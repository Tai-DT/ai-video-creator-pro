### Sample Analysis
```
PHÂN TÍCH KỊCH BẢN PHỞ VIỆT NAM:

SCENE 1: Giới thiệu (0:00-0:15)
- Visual: Người dẫn chương trình đứng trước bàn bếp
- Camera: Medium shot
- Props: Bàn bếp, nồi, dụng cụ nấu ăn

SCENE 2: Chuẩn bị nguyên liệu (0:15-0:45)
- Visual: Hiển thị từng nguyên liệu một cách rõ ràng
- Camera: Close-up shots
- Props: Xương bò, thịt bò, bánh phở, gia vị

SCENE 3: Nấu nước dùng (0:45-2:00)
- Visual: Quá trình nấu nước dùng từng bước
- Camera: Overhead shot + close-up
- Props: Nồi lớn, lửa, nguyên liệu

SCENE 4: Trình bày (2:30-3:00)
- Visual: Cách trình bày phở đẹp mắt
- Camera: Top-down shot
- Props: Tô phở, rau thơm, gia vị
```

## Testing Steps

1. **Start the application**: `npm run dev`
2. **Add API Key**: Get a Google AI Studio API key and add it
3. **Test Script Creation**: Use the sample script data
4. **Test Script Analysis**: Use the sample analysis data
5. **Test Image Generation**: Generate 4 images
6. **Test Video Creation**: Create a video with the generated content
7. **Test Project Saving**: Save the project with a name
8. **Test Project History**: View saved projects
